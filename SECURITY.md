# Security Policy

## Supported Surface

Security reports are welcome for the actively maintained repository surfaces:

- `apps/web`
- `apps/extension`
- `apps/desktop`
- `apps/server`
- `packages/core`
- `packages/ui`
- `packages/node`

Historical planning documents under `docs/history/` are out of scope unless a report demonstrates an issue in active code or public documentation.

## Reporting a Vulnerability

Please avoid filing public issues for unpatched security problems. Instead, contact the maintainer directly with:

- a short description of the issue
- affected files, routes, or hosts
- reproduction steps or proof-of-concept details
- any suggested mitigation or expected impact

## Response Goals

- Acknowledge the report within 5 business days.
- Reproduce and triage the issue before discussing disclosure timing.
- Ship a fix or mitigation before requesting public disclosure where possible.
