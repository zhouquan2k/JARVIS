# Code of Conduct

## Our Standard

This project expects contributors to communicate clearly, review work rigorously, and disagree without hostility. Participation should stay focused on the technical problem, documented evidence, and respectful collaboration.

## Expected Behavior

- Be specific about bugs, risks, assumptions, and trade-offs.
- Give actionable feedback instead of personal criticism.
- Respect language differences and use the documented mirror structure for public docs.
- Protect private credentials, conversations, and user data while discussing issues.

## Unacceptable Behavior

- Harassment, discrimination, or sustained disruption.
- Sharing private data, tokens, or confidential conversation content without permission.
- Dismissing contributors with personal attacks instead of technical arguments.

## Enforcement

Project maintainers may edit, hide, or remove content that violates this code of conduct and may restrict access for repeated violations.
