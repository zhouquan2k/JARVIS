## 新增需求

### 需求：群组轮次必须渲染为标签页消息卡片
当群组对话轮次有超过一个参与成员时，assistant 消息应渲染为标签页卡片，包含一个 `Summary`（摘要）标签和每个成员各一个标签。当只有一个成员参与时，系统应使用该成员的内容渲染普通气泡。

#### 场景：多成员群组轮次渲染标签页
- **当** 一条 assistant 消息的 `groupMembers` 有 2 个或更多条目时
- **则** 系统必须渲染带有标签的卡片：`[Summary] [成员A] [成员B] …`
- **且** 标签标题必须包含成员名称和状态指示点

#### 场景：单成员群组轮次降级为普通气泡
- **当** 一条 assistant 消息的 `groupMembers` 只有 1 个条目时
- **则** 系统必须使用该成员的内容渲染普通 Markdown 气泡
- **且** 不得显示 `Summary` 标签

#### 场景：无 groupMembers 的遗留消息正常渲染
- **当** 一条 assistant 消息没有 `groupMembers` 字段时
- **则** 系统必须通过现有的 `MarkdownContent` 路径渲染它
- **且** 不得发生错误

### 需求：标签状态指示器必须反映成员流式状态
每个成员标签标题应显示反映该成员回复当前状态的视觉状态指示器。

#### 场景：成员仍在生成中
- **当** 成员的 `status` 为 `'streaming'` 或 `'pending'` 时
- **则** 该标签的指示器必须显示进行中状态（旋转图标或动态点）

#### 场景：成员已完成
- **当** 成员的 `status` 为 `'done'` 时
- **则** 该标签的指示器必须显示已完成状态（实心点）

#### 场景：成员失败
- **当** 成员的 `status` 为 `'error'` 时
- **则** 该标签的指示器必须显示错误状态（红色点）
- **且** 标签内容区域必须显示错误信息

### 需求：默认标签选择必须遵循定义的生命周期
活跃标签应遵循定义的生命周期：流式传输期间为第一个成员，摘要生成完成后（用户未手动切换时）自动切换到 Summary。

#### 场景：流式传输期间默认标签
- **当** 群组轮次开始流式传输时
- **则** 系统必须默认显示第一个成员的标签

#### 场景：完成后自动切换到 Summary
- **当** `groupSummary.phase` 变为 `'done'` 时
- **且** 用户在本轮次中未手动切换标签时
- **则** 系统必须自动将活跃标签设置为 `Summary`

#### 场景：尊重手动标签选择
- **当** 用户在当前轮次中手动点击了某个标签时
- **则** 摘要生成完成后系统不得自动切换活跃标签
- **且** 活跃标签必须保持在用户最后选择的标签

#### 场景：已完成的历史轮次默认显示 Summary
- **当** 显示历史群组轮次消息（已完全完成）时
- **则** 系统必须默认显示 `Summary` 标签

### 需求：Summary 标签必须显示带成员归因的结构化综合内容
`Summary` 标签应显示综合内容，包含三个部分（共识、互补见解、分歧）。内容中的 `@成员名称` token 应渲染为可点击的 chip，点击后导航到对应成员的标签。

#### 场景：Summary 渲染三个部分
- **当** `groupSummary.phase` 为 `'done'` 时
- **则** 系统必须在 `Summary` 标签中渲染摘要内容

#### 场景：@成员 chip 导航到成员标签
- **当** 摘要内容包含与成员标签匹配的 `@成员名称` token 时
- **则** 系统必须将该 token 渲染为可点击的 chip
- **且** 点击该 chip 必须将活跃标签切换到对应成员的标签

#### 场景：无 @token 的摘要渲染为纯 Markdown
- **当** 摘要内容不包含 `@成员名称` token 时
- **则** 系统必须将内容渲染为纯 Markdown，不得报错

### 需求：Summary 标签在生成期间必须显示进度状态
摘要生成器运行期间，`Summary` 标签应显示列出每个成员完成状态的进度视图。

#### 场景：流式传输期间 Summary 标签显示成员进度
- **当** `groupSummary.phase` 为 `'waiting'` 或 `'streaming'` 时
- **则** `Summary` 标签必须显示每个成员的名称和完成状态（已完成 ✓ / 进行中…）
- **且** 摘要内容的部分内容应在流式传输时逐渐显示
