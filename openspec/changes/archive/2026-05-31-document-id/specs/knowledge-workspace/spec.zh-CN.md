## 新增需求

### 需求：知识工作区必须在执行节点移动前弹出移动确认框
在执行任何移动操作（拖放或右键菜单）前，工作区必须显示模态确认框。确认框必须展示被移动的节点和目标位置，并在 Markdown 出链将被重写时给出提示。移动操作必须等用户明确确认后才能执行。

#### 场景：agent 内移动前显示确认框
- **当** 用户发起移动操作（拖放放下或右键菜单"移动到"确认）
- **且** 该移动在同一 agent 内
- **则** 工作区必须在执行移动前显示确认框
- **且** 确认框必须展示被移动节点的名称和目标目录路径
- **且** 确认框必须提供"移动"确认按钮和"取消"按钮

#### 场景：当 Markdown 链接将被重写时确认框给出提示
- **当** 确认框为移动某 `.md` 文档而显示
- **且** 该文档包含相对图片或文档链接
- **则** 确认框必须包含文档内出链将被自动更新的提示
- **且** 该提示必须在用户确认前可见

#### 场景：取消操作中止移动
- **当** 确认框已显示
- **且** 用户点击"取消"或关闭确认框
- **则** 移动操作必须不被执行
- **且** 节点必须保留在其原始位置

---

### 需求：知识工作区必须在尝试跨 agent 移动时弹出阻断性错误框
当用户发起的移动操作将跨越 agent 边界时，工作区必须以阻断性错误框替代确认框。错误必须清晰说明不支持跨 agent 移动。移动操作必须不被执行。

#### 场景：跨 agent 拖放时显示错误框而非确认框
- **当** 用户将节点拖放到属于不同 agent 的目录上
- **则** 工作区必须显示阻断性错误框（而非确认框）
- **且** 错误框必须说明不支持跨 agent 移动
- **且** 节点必须保留在其原始位置

#### 场景：跨 agent 右键菜单移动时显示错误框
- **当** 用户在文件树右键菜单中选择"移动到"
- **且** 所选目标目录属于不同的 agent
- **则** 工作区必须显示相同的阻断性错误框
- **且** 节点必须不被移动

#### 场景：错误框可被关闭
- **当** 阻断性错误框已显示
- **则** 用户必须能通过单次操作关闭（如"确定"按钮或 Escape 键）
- **且** 关闭后节点必须保留在其原始位置

---

### 需求：知识工作区必须在文档移动时重写出链相对路径
当 `.md` 文档在其 agent 内移动时，工作区必须重写该文档内所有相对图片和文档链接路径，使其在新位置仍然有效。任何时候都必须使用标准相对路径语法（`./`、`../`），以保持与外部 Markdown 工具的兼容性。不引入任何自定义路径语法。

#### 场景：文档移动后更新相对图片路径
- **当** 用户将 `.md` 文档移动到同一 agent 内的不同目录
- **且** 该文档包含相对图片引用（如 `../references/arch.png`）
- **则** 工作区必须重写每个相对引用，使其从新位置仍解析到相同的目标文件
- **且** 重写后的路径必须是任何 Markdown 渲染器都能正确解析的标准相对路径

#### 场景：文档移动后更新相对文档链接
- **当** 用户将 `.md` 文档移动到同一 agent 内的不同目录
- **且** 该文档包含到其他文档的相对链接（如 `./notes/setup.md`）
- **则** 工作区必须重写这些链接，使其在新文档位置仍然有效

#### 场景：重写在写入前先在内存中计算
- **当** 工作区在移动后计算出链重写
- **则** 新内容必须在任何写入操作开始前完全在内存中计算完毕
- **且** 若写入失败，文档必须保留其原始内容和原始（移动前的）相对路径

#### 场景：旧文档不自动重写
- **当** 未被移动的文档包含现有相对路径
- **则** 工作区不得自动重写这些路径
- **且** 现有相对路径必须继续按原有方式正确解析

#### 场景：`references/` 目录不能单独移动
- **当** 用户尝试单独移动 `references/` 目录（而非作为父目录移动的一部分）
- **则** 工作区必须拒绝该操作并显示清晰的错误消息
- **且** 该目录必须保留在其原始位置
