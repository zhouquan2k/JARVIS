English | [Chinese](spec.zh-CN.md) ## MODIFIED Requirements ### Requirement: Background Proxy Forwarding
The system MUST provide一个运行于 Background 的代理机制，并expose对应的 UI 替身 Provider，以绕过浏览器插件内容脚本的 CORS 限制。代理协议 MUST support请求关联标识（如 `requestId`/`channelId`）以隔离普通聊天、对比分析与external historyquery等并发流，并support多模态发送参数与标准化的结构化流式update。 #### Scenario: Proxy sendMessage to actual provider with request correlation
- **WHEN** UI 层调用 `BackgroundProxyProvider.sendMessage` 并附带所需configuration项及 Payload（如 `{ providerId: 'gemini-api', modelId: 'gemini-2.5-flash', attachments: [...] }`）
- **THEN** 替身 Provider MUST 通过长连接将指令发送至 Background 脚本，且message MUST 携带可关联的请求标识
- **AND** Background MUST 作为无状态route分发引擎，根据 `providerId` 动态实例化对应真实 Provider
- **AND** Background 随后 MUST 向该 Provider 发起真实请求，并按请求标识将标准化的 `ProviderStreamUpdate` 流独立回传到对应前端请求上下文 #### Scenario: Proxy forwards comparison analysis request through background
- **WHEN** UI 层发送分析指令（例如 `ANALYZE_COMPARISON`）并包含 `prompt`、`outputA`、`outputB`
- **THEN** Background MUST 在后台执行分析流程并流式回传分析增量
- **AND** UI MUST only消费与该分析请求标识匹配的回包数据，不得与 A/B 原生output流混淆 #### Scenario: Proxy forwards external history list request
- **WHEN** UI 层发送 `GET_HISTORY_LIST` 指令并包含目标history provider 标识，且未provide `query` 或 `query` 为空
- **THEN** Background MUST resolve该请求并调用对应history provider 的最近listquerycapability
- **AND** Background MUST 以与请求标识关联的result回包return标准化historysummary数组 #### Scenario: Proxy forwards searched external history list request
- **WHEN** UI 层发送 `GET_HISTORY_LIST` 指令并包含目标history provider 标识与非空 `query`
- **THEN** Background MUST 将该 `query` 原样透传给对应history provider 的listquerycapability
- **AND** Background MUST 以与请求标识关联的result回包return标准化searchresultsummary数组 #### Scenario: Proxy forwards external history detail request
- **WHEN** UI 层发送 `GET_HISTORY_DETAIL` 指令并包含 `externalId`
- **THEN** Background MUST 获取对应的远端historydetails并在回包前完成标准化转换
- **AND** UI MUST 收到统一的 `Conversation` result而不是第三方原始树状数据 #### Scenario: Proxy forwards provider model catalog request
- **WHEN** UI 层发送 `GET_AVAILABLE_MODELS` 指令并包含目标 provider 标识
- **THEN** Background MUST 调用对应 provider 的modeldirectoryquerycapability
- **AND** Background MUST 以与请求标识关联的result回包return `models/defaultModel` #### Scenario: Abort targets the intended in-flight request
- **WHEN** UI 层发送 `abort` 指令并携带目标请求标识
- **THEN** Background MUST only中止对应请求的 Provider 调用
- **AND** 其他并发中的请求流 MUST keepcontinue执行
