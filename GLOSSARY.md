# Repository Glossary

This glossary defines the canonical terminology for Phase 1 public documentation. Public-facing docs should follow these names consistently.

| English | 中文 | Notes |
| --- | --- | --- |
| ChatPrism | ChatPrism | Canonical product name; do not use `ChatPrizm` in new public docs. |
| Browser Extension App | 浏览器扩展应用 | Browser-hosted product surface. |
| Web App | Web 应用 | Browser-based main host. |
| Desktop App | 桌面应用 | Electron-based desktop host. |
| Sync Server | 同步服务 | Backend service for sync, context APIs, and provider configuration. |
| Knowledge Repository | 知识资料库 | External or local document store used by the workspace. |
| Knowledge Workspace | 知识工作区 | Document-centric workspace inside ChatPrism. |
| Context Provider | 上下文提供方 | Contract for reading and querying scoped workspace context. |
| Model Provider | 模型提供方 | Contract for executing model requests. |
| OpenSpec | OpenSpec | Change-driven specification workflow used in this repository. |
| English Primary File | 英文主文件 | Primary file in a bilingual OpenSpec or public-doc pair. |
| Chinese Mirror | 中文镜像 | Chinese counterpart of an English primary document. |
| Public Entry Document | 公开入口文档 | Reader-facing repository documentation. |
| Historical Docs | 历史文档 | Legacy phase documents under `docs/history/`; out of Phase 1 migration scope. |
